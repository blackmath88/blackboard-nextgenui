# Knowledge and learning workbench — UI research proposal
2026-11-27 | Design note

The existing pilot demonstrates typed proposals, evidence, consent, adaptive frames and deterministic fixture-based experiments. The report distinguishes mock-model tests from real-model acceptance. Preserve the repository as a UI research laboratory, not a new canonical knowledge or execution store.

Explore multiple projections over the same typed evidence: portfolio, topic, project, engineering patterns, hypotheses/trials, provenance and operations. A model may propose bounded presentation changes; it must not mutate underlying facts, authority or permissions. Compare adaptive views against a fixed view on identical synthetic tasks, record accuracy, evidence retrieval, steps and accessibility. Port qualified components to downstream applications rather than requiring a second production shell. No real corpus or new service in this public design note.
